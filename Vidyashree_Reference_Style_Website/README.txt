VIDYASHREE & BALACHANDRU WEDDING INVITATION

Reference-inspired mobile scrolling wedding invitation.

1. Extract ZIP.
2. Open index.html in a browser (or VS Code Live Server).
3. Tap OPEN INVITATION to view the full website.
4. To add music, save a legally obtained MP3 as assets/wedding-music.mp3.
5. Publish via Netlify Drop, Vercel, or GitHub Pages for a shareable URL.
6. Confirm the venue pin on Google Maps before sharing.

Note: The reference video shows a website filmed on a phone. This is a newly coded approximation of its visible style and sections, not a copy of the original site/source code. No couple photos are used.
